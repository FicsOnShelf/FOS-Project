# Fics On Shelf (FOS) — Frontend 📚✨

[English version below](#english-version)

## 🇧🇷 Sobre o Projeto

O **Fics On Shelf (FOS)** é uma plataforma global de organização, avaliação e engajamento social feita sob medida para a comunidade de leitores de fanfictions. Este repositório armazena a interface visual (frontend) da aplicação, projetada com foco em usabilidade, design limpo e uma experiência fluida para que os usuários possam catalogar suas leituras, escrever resenhas e interagir com outros fãs.

### 🛠️ Tecnologias Utilizadas

A estrutura visual e as interações desta interface foram desenvolvidas utilizando tecnologias web nativas, garantindo leveza e performance:

* **HTML5:** Estruturação semântica de todas as telas, componentes e acessibilidade.
* **CSS3:** Estilização customizada, layout responsivo (adaptável para dispositivos móveis e desktop) e animações de interface.
* **JavaScript (ES6+):** Manipulação dinâmica do DOM, controle de rotas lógicas da interface, validações de formulários e integração assíncrona.

# Fics On Shelf (FOS) — Frontend 📚✨

## 🇺🇸 About the Project

**Fics On Shelf (FOS)** is a global platform for organizing, reviewing, and socially engaging within the fanfiction reader community. This repository contains the visual interface (frontend) of the application, designed with a strong focus on usability, clean UI, and a seamless UX, allowing users to catalog their readings, write reviews, and interact with other fans.

### 🛠️ Technologies Used

The visual structure and interface interactions were built using native web technologies, ensuring a lightweight and high-performing application:

* **HTML5:** Semantic structuring of all screens, UI components, and accessibility features.
* **CSS3:** Custom styling, responsive layout (mobile-first and desktop adaptations), and interface animations.
* **JavaScript (ES6+):** Dynamic DOM manipulation, frontend routing logic, form validations, and asynchronous integration.
