# 📚 Fanfic Manager Backend

### **`PT-BR`** 
Este projeto é um **backend em Node.js + TypeScript + Express + Prisma** para gerenciar fanfics, estantes e interações entre usuários (seguir/deixar de seguir).  
Ele inclui scraping automático de fanfics do **AO3** e **Wattpad**, além de CRUD completo para fanfics, estantes e sistema de seguidores.

### **`EN`**
This project is a **backend in Node.js + TypeScript + Express + Prisma** to manage fanfics, shelves, and interactions between users (follow/unfollow). 
It includes automatic scraping of fanfics from **AO3** and **Wattpad**, as well as a complete CRUD for fanfics, shelves, and the follower system.

---

## 🚀 Tecnologias utilizadas / Tech Stack

### **`PT-BR`** 
- **Node.js** + **Express** → servidor HTTP
- **TypeScript** → tipagem estática
- **Prisma ORM** → acesso ao banco de dados
- **SQLite/PostgreSQL/MySQL** → banco de dados (configurável)
- **Axios** + **Cheerio** → web scraping de fanfics

### **`EN`**
- **Node.js** + **Express** → HTTP server
- **TypeScript** → static typing
- **Prisma ORM** → database access
- **SQLite/PostgreSQL/MySQL** → database (configurable)
- **Axios** + **Cheerio** → fanfic web scraping
